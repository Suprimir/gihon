## 🚀 Scripts

- `bun run tauri dev` → Ejecuta la app Tauri en modo desarrollo.
- `bun run tauri build` → Genera el ejecutable final.

## 🧰 Requisitos

- Bun >= 1.1
- Rust + Cargo
- Tauri CLI (incluido como dependencia del proyecto)
